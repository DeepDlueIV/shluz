Локальное тестирование

Проверка запроса

Здесь можно проверить доступ пользователя без технической документации. Используется только тестовая модель mock-chat, без обращения к Venice.

Личный токен — что это?

Это длинная строка shluz_…, которую вы получили кнопкой «Выдать доступ» у тестового пользователя. Она сообщает серверу, от чьего имени выполнить запрос. Это не пароль панели и не ключ Venice.

Ещё нет токена? Откройте «Пользователи», назначьте пользователю тестовый тариф и выдайте доступ. Потерянный токен нельзя посмотреть повторно — отзовите его и создайте новый.

{% if not mock_enabled %}

Эта проверка отключена: включён реальный поставщик. Для бесплатного теста задайте SHLUZ_ACTIVE_PROVIDER=mock и перезапустите приложение.

{% endif %}
Вставьте токен целиком, без слова Bearer. Токен не сохраняется в браузерном хранилище. При закрытии страницы поле очищается.

Ответ появится здесь

Введите личный токен и нажмите кнопку.
Продолжаем проверку, на которой остановились

Тариф с кодом test и лимитом 2 запроса в месяц → пользователь → назначить тариф → выдать токен → вставить выше.

Сделайте три запроса: первые два должны пройти, третий — получить отказ по лимиту. Если пользователь уже делал запросы, они тоже учитываются. Откройте Расходы и проверьте записи.

У mock-модели стоимость и количество токенов равны нулю — для этой проверки это нормально. Проверяем доступ и число запросов, а не настоящий счёт Venice.
