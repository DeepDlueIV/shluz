# Shluz Telegram Bot

Закрытый Telegram-интерфейс Shluz.

Границы:

- бот не обращается к моделям напрямую;
- бот использует только HTTP API Shluz;
- биллинг, тарифы и лимиты остаются в шлюзе;
- токены поставщиков не передаются в бот.

Текущий статус: компонент создаётся в рамках закрытого теста.

План:

1. aiogram 3.x + long polling.
2. Отдельное хранилище истории диалогов.
3. Симуляция Telegram API для CI.
4. Интеграция с mock-провайдером шлюза.
