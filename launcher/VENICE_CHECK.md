# Проверка Venice одним запуском

Откройте Check-Venice.cmd. Установка новых программ и пакетов не нужна: Python 3.12+
уже используется запускателем. Проверка не обновляет приложение и не меняет БД.

Ключ ищется только в локальных настройках Shluz и окружении его контейнера. Если ключ
не найден, программа попросит вставить его скрытым вводом в это же окно. Ключ не
сохраняется и не нужен в переписке. Разрешён только api.venice.ai с проверкой TLS,
без перенаправлений; профили сети/VPN не меняются.

Программа сначала проверяет доступ через /api_keys/rate_limits, затем каталог моделей.
Для ранее выбранной владельцем zai-org-glm-5-2 допускается ОДИН короткий потоковый
запрос с max_completion_tokens=128. По актуальным ценам каталога предварительная
оценка должна быть <=0.01 USD, иначе запроса не будет. Это оценка, не гарантия чужого
биллинга при изменениях цен/контракта. Запросов инструментов, поиска и файлов нет.

Неизвестный результат не повторяется. Новый ручной запуск — новая отдельная проверка.
Отчёт: %LOCALAPPDATA%\Shluz\reports\venice-check.json. Он содержит статус API,
токены/стоимость, когда они сообщены, и признак получения текста; не содержит ключа,
вопроса или ответа. Недоступность сети не объявляется неверным ключом. Стоимость null
не означает бесплатность; 128 токенов иногда уходят на reasoning без видимого текста.
Замер first_text_ms здесь начинается после получения HTTP-заголовков, не с клика.

Это проверка поставщика с компьютера владельца, НЕ end-to-end тест его бота или сайта.
Сетевые ограничения удалённой среды ChatGPT не зависят от VPN на этом компьютере.
Рабочий Shluz остаётся на mock. Публичное платное демо не включается.
