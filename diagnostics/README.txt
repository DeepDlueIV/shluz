NoClip / SHLUZ — безопасная диагностика меню Telegram

Причина: после запуска шлюза Telegram не подтверждает новое меню Mini App.
Прежние попытки закончились откатом к предыдущему коду.

ЧТО ДЕЛАТЬ:
1. Распакуйте этот архив в любую временную папку (не поверх D:\NoClip\Shluz).
2. Откройте Diagnose-NoClip.cmd.
3. Пришлите файл NoClip-Telegram-Diagnostic.txt из той же временной папки.

Диагностика НЕ перезапускает шлюз, НЕ трогает Docker volumes,
НЕ меняет меню Telegram, ключи, сайты или конфигурации.
Она безопасно читает статус контейнеров и текущие значения меню
через официальный Telegram Bot API (без платных запросов).
Токены, Telegram ID, URL, пароли, SQL, API-ключи и сырые Docker inspect
не выводятся и не сохраняются в отчёт.

Если Telegram API недоступен, в отчёте будет указан тип сбоя.
Не присылайте сырые файлы .env, docker inspect, SQLite или bot token.

Эта диагностика помогает установить реальную причину, но не заявляет,
что Telegram Mini App уже исправлена. Пользовательские данные остаются.
