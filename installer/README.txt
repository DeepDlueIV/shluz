NoClip / SHLUZ — обновление локальной программы

НАЗНАЧЕНИЕ: обновить существующую установку D:\NoClip\Shluz.

1. Скачайте проверенный NoClip-OneClick.zip из GitHub Release.
2. Распакуйте архив в любую временную папку (например, Downloads).
3. Дважды нажмите Install-NoClip.cmd. Больше ничего переносить не нужно.

Установщик проверит SHA-256 всех файлов, существующий Docker, владельца
контейнеров, создаст копию заменяемого кода, обновит лаунчер и запустит NoClip.
После установки откроет существующую админку: http://127.0.0.1:18000/admin

Подтверждение новой Telegram Mini App проверяется внутри контейнера бота,
поскольку Windows/VPN иногда блокирует обращение к Telegram API.
Если оба пути проверки временно недоступны, работающие Gateway и бот
НЕ останавливаются: будет выведено предупреждение о неподтверждённом меню.
Повторный NoClip.cmd проверяет меню без пересоздания контейнеров и без
повторного переноса данных. Если Telegram достоверно сообщает неверный URL
и его не удаётся исправить, запуск остановится, чтобы не показывать
ложный успех.

Ваши ключи, пользователи, диалоги, база Docker, ngrok, Cloudflare,
пароли, конфигурация сайта и существующие резервные копии НЕ копируются
в скачанный архив, НЕ удаляются и НЕ перезаписываются обновлением.
Гостевой сайт-туннель, если был запущен, продолжит работать отдельно.

Управление после установки:
 D:\NoClip\Shluz\NoClip.cmd — запустить SHLUZ и Telegram Mini App
 D:\NoClip\Shluz\Stop-NoClip.cmd — остановить SHLUZ и Telegram
 D:\NoClip\Shluz\Start-Website.cmd — сайт и отдельный ngrok
 D:\NoClip\Shluz\Stop-Website.cmd — остановить только сайт-туннель
 D:\NoClip\Shluz\Backup-NoClip.cmd — архивировать пользовательские базы

Снимки предыдущего кода хранятся в скрытой .noclip-installer/history.
Автоматически сохраняются две последние собственные копии программы.
Это не резервные копии пользовательских баз; backups/ и Docker volumes
никогда не удаляются установщиком. Неизвестные старые файлы не удаляются
без проверки. После успешной установки папку распаковки можно удалить.

Важно: эта сборка обновляет только локальный лаунчер и скрипты управления.
Образ основного Gateway закреплён на проверенной версии c47ff5b8.
Переключение Gateway на новую версию с изменением схемы БД требует
отдельно проверенной миграции, не запускается автоматически этим ZIP.

Если существующая папка одновременно является Git-копией, установщик
РАЗРЕШАЕТ обновление после проверки Git и не трогает историю коммитов.
Если Codex ещё не сохранил изменения скриптов, обновление остановится
без перезаписи. Чужие правки сайта и документов не мешают установке.
Важно: обновлённые скрипты могут появиться как изменённые файлы Git.
Не запускайте git add -A без просмотра изменений; отдельный Git-клон
для разработки — рекомендация, но не обязательное условие запуска.

Не загружайте config/, backups/, live-miniapp/ и .noclip-installer/
в GitHub. Новая сборка не требует переноса файлов из AppData.

Где данные: настройки — D:\NoClip\Shluz\config\, Mini App —
D:\NoClip\Shluz\live-miniapp\, резервные копии — backups\.
Пользователи, кошельки и история находятся в Docker named volumes;
часть старых копий может оставаться в %LOCALAPPDATA%\Shluz.
Это переносимый лаунчер, а НЕ автономная portable-база на USB.
