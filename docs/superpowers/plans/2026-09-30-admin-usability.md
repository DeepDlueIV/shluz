# План исправлений панели Shluz

> Выполнение: superpowers:executing-plans, по этапам с проверками.

**Goal:** исправить формы и тему, добавить безопасный архив и доступные журналы.
**Architecture:** сохранить FastAPI/Jinja2/SQLAlchemy; формы и бизнес-действия остаются на сервере, новые вспомогательные страницы вынести из большого routes.py.
**Tech Stack:** текущие зависимости проекта, без новых библиотек.
**Spec:** docs/superpowers/specs/2026-09-30-admin-usability.md

## Общие ограничения
- Только отдельная ветка feat/admin-usability; main обновлять после зелёных проверок.
- Не удалять строки пользователей, тарифов, подписок или расходов.
- Не трогать удалённый Supabase и настоящие ключи поставщиков.
- Сообщения панели на русском; публичные API-ошибки сохраняют прежний формат.
- В журнале не должно быть полных ключей, паролей, содержимого сообщений или query string.

## Проверить особо
- Код тарифа на русском, дубль кода, отрицательные значения: форма и введённые данные сохраняются.
- Архивирование требует авторизации, CSRF и подтверждения; действующие подписки не лишаются тарифа случайно.
- После восстановления пользователя старые токены не оживают.
- Ошибка журналирования не раскрывает секреты; успешное админ-действие и его запись атомарны.
- API продолжает возвращать JSON, а панель — HTML; простая тестовая страница не обходит тарифы.

## Журнал восстановления и проверки

Исходная основная версия: 82082459d174d86198a08d0c627bf59ef1c8b53b.
Незавершённая ветка обнаружена на c3c41edebe0e883f1472e8c3b99c99e29cf5e6e0; Pull Request №9 оставался черновиком.

Причина первого сбоя: неэкранированный дефис в HTML pattern, недопустимый в Unicode Sets mode. Ошибка воспроизведена отдельно через Node.js; исправленное выражение принимает test, Pro, pro-1 и test_2 и отклоняет кириллицу и пробелы.

Причина второго сбоя: старый тест требовал текст заглушки, заменённой работающими разделами. Теперь он проверяет ссылки на провайдера, журнал, тестовую страницу и честное предупреждение о неподключённых платежах.

После исправления выявлено ещё одно устаревшее ожидание старого pattern в тесте HTML; оно согласовано с проверенным браузерным выражением, без удаления регрессионного теста.

Все шаги, включая миграцию, тесты, Docker build и Docker runtime, завершились успешно.

Работа выполнена через GitHub connector: локальный git clone в среде разработчика недоступен из-за DNS. Изолированная ветка сохранена; пользовательский компьютер и удалённый Supabase не изменялись. Полного визуального прогона в браузере разработчика не было: удобство и внешний вид остаются предметом локальной приёмки владельца.
