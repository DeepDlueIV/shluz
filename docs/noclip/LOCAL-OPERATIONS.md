# Управление NoClip / SHLUZ в Windows

Рабочая папка: `D:\NoClip\Shluz`.

## Запуск всего контура

Откройте `D:\NoClip\Shluz\NoClip.cmd`. Один файл запускает основной Gateway, Telegram Mini App и его HTTPS-туннель, гостевой Gateway сайта и защищённый ngrok-туннель. При успехе открываются Telegram и сайт. Туннель сайта использует закреплённый адрес, уже подключённый к Vercel.

## Остановка всего контура

Откройте `D:\NoClip\Shluz\Stop-NoClip.cmd`. Остановятся сайт и его туннель, Telegram Mini App и HTTPS-туннель, основной Gateway. Контейнеры, базы, ключи и истории останутся на месте. После Stop локальная админка временно недоступна; для запуска снова используйте `NoClip.cmd`.

## Админка

Локальная админка: `http://127.0.0.1:18000/admin`.

Настройки гостевого сайта: `http://127.0.0.1:18000/admin/access?scope=site`. Там же ссылка «Защита демо / Demo protection». Переключатель «Основной SHLUZ / Гостевой сайт» показывает, к какой базе применяются изменения. Настройки новых гостей не возвращают запросы уже исчерпанным гостевым допускам.

В этой версии запуск/остановка сервисов из веб-панели ещё не реализованы: для них используйте два указанных файла. Панель не получает доступ к Docker или командам Windows.
