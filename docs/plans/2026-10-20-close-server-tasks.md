# Завершение серверного блока

Основание: владелец попросил закончить согласованные незавершённые работы; оплатил
Venice и разрешил ограниченные проверки. Базовый исходник: 08145402.

1. Закрыть официальный Telegram Login браузера через текущую официальную JS-библиотеку
   и серверную проверку OIDC ID-token (RS256, JWKS Telegram, aud/iss/exp/iat/nonce).
   Случайный nonce связан с cookie/CSRF и погашается атомарно. Совпадающий Telegram ID
   ведёт в прежний Account бота; email-аккаунты/деньги автоматически не объединяются.
2. Добавить контракт, состояния готовности, миграцию и негативные тесты реальных
   криптографических подписей с изолированным JWKS HTTP transport.
3. Подготовить отдельную однокнопочную ограниченную проверку Venice: ключ только локально,
   без включения провайдера для всех пользователей, без отправки секретов/ответов в отчёт.
4. Связанные тесты, затем полный набор и миграции. Проверить публикацию отдельно от кода.

Границы: SMTP/Turnstile/Telegram Client ID и Allowed URLs требуют настройки сервисов;
их нельзя выдумывать. История/дизайн сайта, привязка существующих кошельков, платежи и
перенос PostgreSQL не относятся к этому блоку. Публичный web и платное demo не включать.

История предыдущего сеанса 20.10.2026: GET Venice остановился на DNS до HTTP, без генераций.
Тогда подключение GitHub предоставляло только чтение. В следующем сеансе команды
записи обнаружены: сохранённый код публикуется без пересоздания проекта.
