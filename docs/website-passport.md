# Веб-направление NoClip

## Принято

- Репозиторий `DeepDlueIV/shluz`; сайт изолирован в `web/`, шлюз и Telegram здесь не перепроектируются.
- Предоставленные видеофон и логотип; поле ввода при прокрутке превращается в закреплённую навигацию с настоящим backdrop blur.
- EN — основной язык первого посещения; RU — дополнительный. Возле входа — глобус; флаги только внутри меню. Выбор языка сохраняется без потери вопроса.
- Без декоративных мелких слоганов и псевдофилософского текста. Компактный заголовок единым начертанием, знак NoClip над ним.
- Нижние демонстрации предварительные; отдельные презентации desktop и Telegram — позже. Новые маркетинговые страницы не создаются.
- Собственная сцена частиц/Blender и обновление бренда отложены.

## Сценарий и контракт

Главная → вопрос в памяти приложения → `/app` → один гостевой запрос → потоковый ответ.
Просмотр главной создаёт только сессию; Account создаёт шлюз при первом допущенном запросе.
Новый подтверждённый email превращает тот же guest Account в постоянный, сохраняя ID и расход демо.

Источники контракта web-access-v1.1:
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/CLIENT_API.md
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/guest-dashboard-journey.md

Payload: `prompt`, `request_id`, `turnstile_token`; модель определяет сервер. Браузер не получает ключей провайдеров и не ведёт собственный биллинг. EOF без `[DONE]` — обрыв; POST автоматически не повторяется.
`NEXT_PUBLIC_GATEWAY_ENABLED=false` остаётся настройкой визуального preview. Живой шлюз, SMTP, OTP, оплата и Turnstile не считаются проверенными.

## Просмотр и доставка

Next.js + React + TypeScript + CSS Modules + Motion. Один Vercel-проект `noclip-web`, Root Directory `web`, ветка `main`; копия репозитория не нужна.
Пользователь подключил Vercel для просмотра и отказался от дальнейшей работы над запускатором. Обычные commit/push и публикация правок preview разрешены. Платные изменения и перенос хостинга не выполняются.
GitHub → Vercel автосборка подключена; прямой MCP-доступ к Vercel team ранее возвращал 403.

## Правки 21.10.2026: первый экран и панель

- Заголовок уменьшен до 48 px на широком экране (ранее до 120 px); логотип сверху. Убраны внутренние дуги `.glassPanel::before`.
- Подсказки при наведении/уходе меняются через fade и горизонтальное смещение за 120 мс. Наведение не заменяет набранный текст; клик по примеру заполняет поле.
- Закреплённая панель: `Ask anything` и стрелка объединены тонкой рамкой в одну кнопку. Нажатие раскрывает ввод на всю ширину, навигация уходит вправо с fade; повторное нажатие восстанавливает навигацию. Переход 160 мс, черновик сохраняется. Escape сворачивает поле; Enter отправляет. Стрелка закреплённой панели переключает режим, а не отправляет запрос.
- Видеофон автоматически запускается без звука и без кнопки Enable animation, в том числе при системном reduced-motion — прямое решение владельца. Если браузер запрещает autoplay, повторная попытка происходит при обычном клике/клавише. Политику браузера сайт не обходит. Вне экрана/скрытой вкладки видео приостанавливается.
- WebM/VP9 и MP4/H264 сохранены для desktop/mobile. WebM подготовлены ранее из предоставленного видео; рендер на Vercel не требует ffmpeg.
- Все 20 названий в двух лентах сохранены. Верхняя строка движется вправо, нижняя влево, без остановки при наведении. Упоминания и ссылки внешнего поставщика удалены из интерфейса, но серверные интеграции не менялись.
- Старые знаки моделей были самодельными SVG-заглушками. Теперь каждому названию сопоставлен знак из Lobe Icons, закреплённая версия `21b2144f4ebe87ead9b7c0e10067759ae261b03e`. SVG хранятся локально в `web/public/media/models`, происхождение — `SOURCES.md`, MIT-лицензия — `web/public/licenses/lobe-icons-MIT.txt`. GLM использует знак Z.ai, Black Forest Labs — BFL. Наличие названия не означает включённую модель или партнёрство.
