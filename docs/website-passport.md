# Веб-направление NoClip

## Принято

- Репозиторий DeepDlueIV/shluz; веб-код изолирован в web/.
- Основная задача этапа: первая главная по Venice, с предоставленным видео и первым логотипом.
- Поле ввода при скролле превращается в закреплённую навигацию, размытие действует на содержимое позади панели.
- Верхние пункты About / Features / Token / Pricing / Resources / Store / Log in временные; новых маркетинговых страниц нет.
- Нижняя структура предварительная; десктоп и Telegram получат отдельные демонстрации позже.
- Пользователь подтвердил сохранение guest Account при регистрации на новый email; расход демо сохраняется.
- Уточнено: просмотр главной создаёт только сессию, Account — первый допущенный запрос.
- Собственная сцена частиц/Blender и обновление бренда отложены; используем загруженные материалы.

## Контракт

Актуальный проверенный контракт web-access-v1.1:
https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/CLIENT_API.md

Сценарий главная → /app → гость → постоянный аккаунт:
https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/guest-dashboard-journey.md

Гостевой запрос: prompt + request_id + turnstile_token; модель определяет сервер.
Фронтенд не создаёт свою базу аккаунтов/тарифов. Самостоятельные запросы к провайдеру запрещены.
Преждевременный EOF без [DONE] — ошибка; POST автоматически не повторяется.
По умолчанию интеграция выключена. Live SMTP/Turnstile/provider не проверены в этой работе.
