# Веб-направление NoClip

## Принято

- Репозиторий `DeepDlueIV/shluz`; сайт изолирован в `web/`, шлюз и Telegram здесь не перепроектируются.
- Предоставленные видеофон и логотип; поле ввода при прокрутке превращается в закреплённую навигацию с настоящим backdrop blur.
- EN — основной язык первого посещения; RU — дополнительный. Возле входа — только глобус; флаги и названия языков внутри меню. Выбор языка сохраняется без потери вопроса.
- Без декоративных мелких слоганов. Компактный заголовок единым начертанием, знак NoClip над ним. В поле ввода логотипа нет.
- Нижние демонстрации предварительные; desktop и Telegram будут представлены отдельно позже. Собственная сцена частиц/Blender и обновление бренда отложены.

## Сценарий и контракт

Главная → вопрос в памяти приложения → `/app` → один гостевой запрос → потоковый ответ.
Просмотр главной создаёт только сессию; Account создаёт шлюз при первом допущенном запросе.
Новый подтверждённый email превращает тот же guest Account в постоянный, сохраняя ID и расход демо.

Источники контракта web-access-v1.1:
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/CLIENT_API.md
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/guest-dashboard-journey.md

Payload: `prompt`, `request_id`, `turnstile_token`; модель определяет сервер. Браузер не получает ключей провайдеров и не ведёт собственный биллинг. EOF без `[DONE]` — обрыв; POST автоматически не повторяется.
`NEXT_PUBLIC_GATEWAY_ENABLED=false` остаётся настройкой визуального просмотра. Живой шлюз, SMTP, OTP, оплата и Turnstile не считаются проверенными.

## Просмотр и доставка

Next.js + React + TypeScript + CSS Modules + Motion. Один Vercel-проект `noclip-web`, ID `prj_IMSWjsl9RU0e8mV1RXv7QyLz0VJD`, Root Directory `web`, ветка `main`. Постоянный адрес: https://noclip-web.vercel.app
Пользователь отказался от запускатора. Обычные commit/push и публикация согласованных правок разрешены. Тариф Hobby и защита деплоев не меняются.

Исправлен прежний диагноз подключения: проект и деплои читаются с projectId **без teamId/slug**; изменение настроек также выполнено. Пустой list_teams не является доказательством отсутствия доступа. Отдельные raw endpoints могут возвращать 403; это не повод переподключать весь аккаунт. Правило закреплено в `web/AGENTS.md`, подробности — `web/VERCEL.md`.

Источником лишних неуспешных публикаций были также Telegram-ветки общего репозитория; проверенная ошибка — `missing_pages_app`. Автоматические preview deployments отключены. Проверки рабочих веток остаются в GitHub Actions; публикуем проверенный `main`. `web/vercel.json` пропускает сборки при отсутствии изменений в `web/`. История прежних ошибок сохранена, дублирующие проекты не создавались.

## Текущий интерфейс

- Заголовок до 48 px (ранее до 120 px), логотип сверху, внутренние дуги поля удалены.
- Приглашение `Ask me anything, privately…`; RU: `Спросите о чём угодно — приватно…`.
- Подсказки меняются последовательно: исчезновение 160 мс, появление 240 мс, без наложения строк. Предпросмотр ограничен 52ch и многоточием; клик вставляет полный текст, наведение не перезаписывает черновик.
- Первая строка: первые четыре предложенных владельцем названия и `More`. Пятое исходное название `Hack a gaming console` не показано, чтобы сохранить выбранную сетку. More открывает ровно десять дополнительных вариантов в двух строках по пять на desktop. На телефоне — две колонки и открытие касанием.
- More использует fade/slide вниз 320 мс; единая прозрачная область удерживает раскрытие между кнопками, уход закрывает его с небольшой задержкой. Поддерживаются клавиатура и Escape. Иконки подсказок — локальные контурные SVG; каталог и переводы в `prompt-suggestions.ts`.
- Закреплённая панель: единая кнопка с тонкой рамкой, переход навигация/ввод за 400 мс, стрелка переключает режим; Enter отправляет, Escape сворачивает. Черновик сохраняется.
- Фон автоматически проигрывается без звука и отдельной кнопки, включая системный reduced-motion по прямому решению владельца. Браузерный запрет autoplay не обходится: повторная попытка при обычном взаимодействии. Вне экрана/в скрытой вкладке видео приостанавливается. WebM/VP9 и MP4/H264 сохранены для desktop/mobile.
- Две ленты 20 брендов движутся в разные стороны без паузы при hover. Иконки из Lobe Icons версии `21b2144f4ebe87ead9b7c0e10067759ae261b03e`, локальные SVG и MIT-лицензия в `web/public`. GLM использует Z.ai, Black Forest Labs — BFL. Наличие названия не означает включённую модель или партнёрство.

## Проверка

Обычный CI имеет только `contents: read` и не изменяет репозиторий. Проверяет unit-тесты, типы, production build, видео, desktop/mobile, языки, toolbar и меню More. Артефакты содержат JSON-результаты и скриншоты. Для конкретного SHA статус CI и READY в Vercel проверяется отдельно; этот документ сам по себе публикацию не подтверждает.
