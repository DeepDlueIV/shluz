# Веб-направление NoClip

## Принято

- Репозиторий `DeepDlueIV/shluz`; сайт изолирован в `web/`, шлюз и Telegram здесь не перепроектируются.
- Главная по структуре Venice: предоставленный видеофон и логотип, поле ввода превращается в закреплённую навигацию с настоящим backdrop blur.
- EN — основной язык и язык первого посещения; RU — дополнительный. Переключатель возле входа, выбор сохраняется без потери введённого вопроса.
- Без декоративных мелких слоганов и псевдофилософского текста. Заголовок одним прямым начертанием.
- Нижние демонстрации предварительные; отдельные презентации desktop и Telegram — позже. Новые маркетинговые страницы не создаются.
- Собственная сцена частиц/Blender и обновление бренда отложены.

## Сценарий и контракт

Главная → вопрос в памяти приложения → `/app` → один гостевой запрос → потоковый ответ.
Просмотр главной создаёт только сессию; Account создаёт шлюз при первом допущенном запросе.
Новый подтверждённый email превращает тот же guest Account в постоянный, сохраняя ID и расход демо.

Источники контракта web-access-v1.1:
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/CLIENT_API.md
- https://github.com/DeepDlueIV/shluz/blob/automation/verified-source-transfer-20261020/docs/guest-dashboard-journey.md

Payload: `prompt`, `request_id`, `turnstile_token`; модель определяет сервер. Браузер не получает ключей провайдеров и не ведёт собственный биллинг. EOF без `[DONE]` — обрыв; POST автоматически не повторяется.
`NEXT_PUBLIC_GATEWAY_ENABLED=false` остаётся настройкой визуального preview. Живой шлюз, SMTP, OTP, оплата и Turnstile не считаются проверенными.

## Просмотр и доставка

Next.js + React + TypeScript + CSS Modules + Motion. Один Vercel-проект `noclip-web`, Root Directory `web`, ветка `main`; копия репозитория не нужна.
Пользователь подключил Vercel для просмотра и отказался от дальнейшей работы над запускатором. Обычные commit/push разрешены. Платные изменения и перенос хостинга не выполняются.
GitHub → Vercel автосборка работает; прямой MCP-доступ к Vercel team пока возвращает 403.

## Правки 21.10.2026

- Английская главная и гостевой экран, русские переводы, флаги SVG и доступное с клавиатуры меню языков.
- Видеоплеер: muted/playsInline/loop, повтор попытки воспроизведения после готовности и взаимодействия, остановка вне видимой области. При системном reduced-motion или запрете autoplay предлагается явное включение анимации, постоянной кнопки паузы нет.
- WebM/VP9 + MP4/H264 для desktop/mobile. В браузерной диагностике H264-only вариант воспроизвёл `DEMUXER_ERROR_NO_SUPPORTED_STREAMS`; WebM добавлен как совместимый источник. Это не доказательство причины на компьютере владельца.
- В `model-catalog.ts` — все 20 названий из двух строк главной Venice, проверенных 21.10.2026. Это семейства/провайдеры, не полный каталог версий и не обещание их доступности в NoClip.
- Прежние SVG-значки моделей были самодельными заглушками, не официальными логотипами. Удалены; в лентах используются названия.
- Верхняя лента движется вправо, нижняя влево; hover не останавливает движение. Системное reduced-motion учитывается, пользователь может явно включить движение.
- CI `web-check.yml`: 17 unit-тестов, TypeScript, production build и браузерные проверки с desktop/mobile скриншотами. Фактический статус конкретной версии проверять в Actions; наличие тестов не означает успешный прогон.

WebM получены из предоставленного видео командой ffmpeg с `libvpx-vp9 -b:v 0 -crf 36 -deadline good -cpu-used 4 -row-mt 1 -threads 4 -pix_fmt yuv420p -an`. Одноразовый генератор удалён после подготовки файлов; Vercel не требует ffmpeg.

Следующий этап — просмотр владельцем и адресные правки, затем отдельная живая интеграция со шлюзом.
