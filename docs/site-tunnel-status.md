# Сайт NoClip: локальное подключение

С 24.10.2026 основной сайт https://noclip-web.vercel.app подключён к локальному SHLUZ и отвечает настоящей моделью Venice Mistral Small 3.2. Публичное демо включено с явного согласия владельца: один запрос на нового гостя, до 10 запросов на весь сайт в сутки, общий денежный предел $0.02 в сутки; ввод до 1000 символов, вывод до 512 токенов.

## Один файл для запуска

Запустить `D:\NoClip\Shluz\Start-Website.cmd`: он запускает существующий гостевой Gateway и защищённый HTTPS ngrok, затем открывает основной сайт. Docker Desktop должен работать. `Stop-Website.cmd` останавливает только эти сервисы, в том числе без state.json. Закрытие браузера само по себе их не останавливает.

`NoClip.cmd` отдельно запускает основной Gateway и Telegram Mini App. Её cloudflared не является туннелем сайта. Админка основного Gateway локальная: http://127.0.0.1:18000/admin.

## Проверенная защита

Vercel → ngrok Basic Auth + allowlist → только POST /v1/web/session, POST /v1/web/chat/completions, GET /v1/web/me. Admin, внутренние API и остальные методы закрыты. Inspector выключен. Turnstile проходит настоящую серверную проверку; cookie Secure/HttpOnly/SameSite=strict, Origin/CSRF проверяются. Числовой остаток запросов не показывается ни на русском, ни на английском.

Секреты и runtime находятся в config/site-bridge вне Git, права owner+SYSTEM. Реальный IP пока не передаётся через цепочку прокси: ограничение сети общее, его верхний предел совпадает с согласованным глобальным лимитом. Расширять публичный доступ и бюджеты до исправления IP-цепочки не следует.
