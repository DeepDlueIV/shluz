# Web access — журнал выполнения

Источник требований: приложенный владельцем SHLUZ_WEB_ACCESS_TASK.md от 19.10.2026.
База: a3e86b5ca0cca781171da5c65d54630ac0e45dad. main и web/ не менять.
Владелец подтвердил выполнение агентом, без передачи работы Codex.

## План
1. Новый demo-default 1, snapshot старых квот, ограничения ввода/времени/расхода.
2. Гостевая cookie-сессия, Turnstile, SQL-счётчики по сети, атомарный допуск.
3. Email OTP без пароля, безопасное перенесение гостевого использования.
4. Общий контракт, админка настроек, миграции, тесты, проверенная публикация.

## Границы
Провайдер Venice/платежи/перенос БД не включать. Настоящие SMTP/Turnstile и HTTPS
настраиваются отдельно; без них публичная выдача должна закрываться, а не имитироваться.
OPFS для гостевого демо не требуется. Никаких Canvas/Audio fingerprint/evercookie.

## Текущее выполнение
- Исходный HEAD проверен через GitHub, спецификация прочитана целиком.
- Локальная среда Python/container отвечает ClientError. Разработка и проверки
  выполняются в изолированной GitHub-ветке/Actions, без запросов к компьютеру владельца.
- Добавлены исходные регрессионные тесты; ожидаются отказы до реализации.

## Реализация и решения
- Локальный runtime восстановился после ClientError; DNS к GitHub/PyPI остаётся
  недоступен. Исходники и инструмент lint доставлены через артефакты собственных
  GitHub Actions. Это тестовые зависимости, не сторонний агент и не компьютер владельца.
- Первый контрактный прогон Actions: три ожидаемых отказа до реализации.
- Реализованы SQL-сессии, HMAC/TTL, CAPTCHA, cookie perimeter, OTP/SMTP, общий резерв
  денег/слота, новый demo-default со снимком лимита, UI и миграция 20261019_09.
- JSON-демо использует upstream stream с deadline, чтобы остановка ожидания не
  оставляла неограниченный поток синхронного inference.
- Ruling: paid demo budget по умолчанию 0, external model без проверенного предела
  полного расхода закрыта — реальной цены и модели владелец ещё не дал.
- Ruling: никакого отдельного fingerprint-провайдера или собственного скрытого трекера;
  cookie+сеть+CAPTCHA+серверные квоты дополняются независимым денежным пределом.
- Миграционный тест сначала не находил DemoLimit; после включения миграции сохранены
  старые три запроса и использованный счётчик, новый пакет получает один.
- Прежние demo-тесты обновлены под явное новое правило одного запроса; проверка
  исторических пакетов из трёх и отсутствие пополнения остаются отдельными сценариями.
- Локальные Chromium HTTP переходы заблокированы политикой среды
  ERR_BLOCKED_BY_ADMINISTRATOR. Политику не меняли: browser acceptance выполняется в CI.
- Готовность к публикации подтверждается следующим полным облачным прогоном, а не
  наличием файлов. SMTP/Turnstile/real Venice живьём ещё не проверялись.
