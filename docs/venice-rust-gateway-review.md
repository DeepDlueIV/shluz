# Venice Learn: Rust LLM Gateway — применимость к Shluz

Источник: https://docs.venice.ai/learn/rust-llm-gateway . Проверено 18.10.2026.
Ранее изучался раздел API; этот пример Learn не был включён в обзор. Это пропуск
обзора, а не технический запрет использовать материал.

Статья описывает серверный пример на Rust/Axum, PostgreSQL/SQLx: аутентификацию
по ключу, фиксированные окна ограничений в PostgreSQL, OpenAI-совместимый chat,
потоковый SSE, OpenTelemetry для токенов/стоимости/задержки и Docker. Это не готовый
Telegram-бот, дизайн сайта, бесплатный API-доступ или хостинг.

**Вывод для проекта (наша оценка):** это тот же архитектурный слой, что Shluz.
Сайт и бот обращаются к одному шлюзу; второй Rust-сервис или переписывание Python
сейчас дублировали бы работающие аккаунты/админку. Пользовательского экрана у примера нет.

Применено в текущем изменении: лимиты резервируются атомарно в БД, источник прав
по модели/каналу централизован в шлюзе, concurrent-регрессии проверяются на SQLite
и PostgreSQL. Ключи поставщика остаются только на сервере; тексты не добавлены в логи.
Наша lifetime-квота отличается от минутного окна статьи: нужны оба ограничения.

SSE и полноценный экспорт OpenTelemetry — полезные будущие дополнения, но **не
реализованы этим этапом**. Не переносим бездумно пример повторов POST/отражения ошибок:
у нас неопределённая генерация не повторяется автоматически, технические ответы
поставщика не показываются пользователю. Уроки статьи применены без копирования её кода.
